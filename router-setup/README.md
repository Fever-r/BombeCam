# Router script

`bombecam-router.sh` is the Block cloud video script for GL.iNet and OpenWrt routers. BombeCam installs it for you when you press **Connect router** in the Firewall tab; this copy is for setting it up by hand.

See [docs/block-cloud-video.md](../docs/block-cloud-video.md#manual-setup-without-bombecam) for the steps, what the script installs, and how to check that blocking works. Run `sh bombecam-router.sh help` on the router for its commands.
